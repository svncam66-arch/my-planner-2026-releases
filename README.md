Публичный канал бинарных релизов. Исходный код приложения здесь не публикуется.

- [Все версии, история изменений и APK-файлы](https://github.com/svncam66-arch/my-planner-2026-releases/releases)
- [Последняя стабильная версия](https://github.com/svncam66-arch/my-planner-2026-releases/releases/latest)

Для каждой версии будут опубликованы APK, файл SHA-256 и заметки с изменениями относительно предыдущего выпуска. Ссылки на последнюю версию заработают после первого стабильного релиза.

Чтобы установить обновление поверх приложения и сохранить данные и локальную модель, должны совпадать идентификатор приложения и сертификат подписи. Android также может запросить разрешение на установку приложений из этого источника.
